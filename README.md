# Lanka Metro Maps

Visualizations of the proposed Lanka Metro transit network, showing its routes and stops in several map styles.

![Lanka Metro Transit logo](source_data/lanka-metro-logo.png)

## Geographic Map

The network plotted using the geographic positions of its stops, preserving the real-world shape and orientation of each route.

![Geographic map of the Lanka Metro network](images/lk_metro_geographic.png)

## Parallel Geographic Map

A geographic view that separates routes running along the same corridor, making shared sections and interchanges easier to distinguish.

![Parallel geographic map of the Lanka Metro network](images/lk_metro_parallel_geographic.png)

## Harry Beck Map

A simplified, octilinear network diagram inspired by Harry Beck's London Underground map, prioritizing route connections and readability over geographic accuracy.

![Harry Beck-style diagram of the Lanka Metro network](images/lk_metro_harry_beck.png)
